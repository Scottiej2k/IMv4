# Timeline: where things stand

Facts that change over the series: who uses *tu* or *Lei* with whom, who knows which secret,
who lives where. `scripts/make_brief.py` puts every fact that is true at a chapter into that
chapter's brief, so writers never have to work it out.

- **From**: the first chapter where the fact is true.
- **Until**: the first chapter where it is no longer true (blank = still true at the end of the series).

Keep this updated when a chapter establishes something later chapters must respect.
